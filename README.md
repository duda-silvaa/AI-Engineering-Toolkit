# AI Engineering Toolkit

Biblioteca de prompts e recursos para desenvolvimento de software com Inteligência Artificial.

O objetivo deste repositório é organizar prompts reutilizáveis para análise de código, desenvolvimento, debugging, arquitetura, testes e documentação.

## Categorias

| Categoria | Descrição |
|---|---|
| Análise de código | Compreensão de projetos e identificação de padrões |
| Desenvolvimento | Planejamento, implementação e refatoração |
| Debugging | Investigação de erros e performance |
| Frontend | React, TypeScript e interfaces |
| Backend e dados | APIs, integrações e bancos de dados |
| Qualidade | Revisão técnica e testes |
| Documentação | Documentação e aprendizado contínuo |

## Como utilizar

1. Acesse a categoria desejada.
2. Abra o arquivo `.txt` correspondente.
3. Copie o prompt.
4. Adapte as informações entre colchetes.
5. Utilize no Claude, ChatGPT ou outra IA.
6. Avalie e ajuste os resultados.

## Objetivo

Construir uma biblioteca organizada e evolutiva de prompts, desenvolvendo boas práticas de Engenharia de Software e uso profissional de Inteligência Artificial.
